## Receipt contract and lifecycle

`editorState.alignmentResetReceipt` is null or the following compact object:

```json
{
  "binding": "<SHA-256 of source/selector/crop/display and exact active plan>",
  "directions": [{"recordKey": "record-1", "before": false, "after": true}],
  "referenceDeltaX": {"recordKey": "record-1", "deltaX": -154}
}
```

Only actual eligible direction changes are stored. Reference Δx is sparse,
finite and nonzero, or null. No direction mode, Custom policy, helper facts,
full translation snapshot or vertical history is persisted. Source binding
hashes actual resource bytes; resource ID renaming is harmless. Stable record /
plan order, style, labels, translations and later ordinary Reverse do not rewrite
the evidence. Cardinality is excluded because reserialization can change
`exactly_one` to `all` for the same selected immutable single source; source
bytes, selector, record identity, crop and anchors remain authenticated.
Python uses the same UTF-16 record-key ordering as Web, including supplementary
Unicode keys.

Positions Reset retains current directions and subtracts only saved reference
Δx once before clearing plan/receipt. Combined Reset restores only the latest
Align's actual changed records to their absolute before values, including the
reference. Affected later manual directions are disclosed in the preview;
unaffected later edits survive. If a direction actually changes, the existing
geometry helper projects exact saved source anchors and corrects current y
placement without stored y history or another LOSAT job. Both scopes consume
plan/receipt through the same transaction.

Align A→B records B's immediate before, with materialized current positions;
returning to A uses History. Style and stable reorder retain valid evidence.
Source/selector/crop invalidation, explicit clear and manual position mutation
clear it with the existing plan/materialization owner. Failure, Cancel, stale
or superseded work preserves the prior artifact and adds no History entry.
Undo/Redo restores resources, canonical request, directions, positions, Result,
plan and receipt together. Save/fresh Load preserves the binding. Malformed or
mismatched modern receipts reject before replacing the current artifact.

Released Session 44/request7 and v40/request5 missing evidence remain readable.
Current request8 aligned documents explicitly encode null for historical absence;
missing modern fields reject. Empty modern direction delta and historical absence
have separate combined-Reset disable reasons; positions Reset remains available.
No Renderer interprets the receipt.

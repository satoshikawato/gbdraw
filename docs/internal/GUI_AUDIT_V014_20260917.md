### Product / architecture preflight

分類は `IMPLEMENT_EXISTING_AUTHORITY`。既存の入力仕様
(`docs/REFERENCE/input-formats-and-tsv-schemas.md` のcase-insensitive regex)、Pythonのルール優先順位、
Web CLAUDEの単一lazy Worker・同期編集・History・Session preview契約を実装する修正である。
ユーザーもPythonとの一致を明示し、日本語対応を除外した。これらと異なる意味の新しい選択肢は導入しない。
`EVIDENCE_REQUIRED` に相当する意味差はCLI/Worker/ブラウザの対照検査で解消した。
未解決のProduct選択肢はなく、`PRODUCT_DECISION_REQUIRED` や `NOT_ALLOWED` の候補は採用していない。
存在しないBD番号や候補内の承認を根拠には使わない。

architecture ratchetは通常の非増加変更としてレビューした。ルール解釈をJS/Pythonの二重ownerから
既存Python ownerへ集約し、JS側のmoduleは一時的な判定結果と入力前処理のみを担当する。
描画要求とResult admissionは既存canonical path、Workerの所有者は既存serviceのまま。
PDFも既存export ownerと同じWorkerを使用する。永続化schemaや互換経路を増やさないため、
OE/PE/CB増加の例外は不要。特権importer/operator、規範・ガード・承認ファイルは変更していない。
rollbackはこの追補コミットのrevertで可能だが、前回のF08とF12ゲート違反も復活するため、
その状態をリリースしない。描画参照SVGとowner管理の公開画像は変更していない。

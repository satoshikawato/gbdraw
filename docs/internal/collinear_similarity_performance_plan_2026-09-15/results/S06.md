## Implementation boundaries

`analysis/ortholog_paths.py` owns ordered path representation, DAG validation,
count/rank/unrank/shared/first-edge dynamic programming, and explicit traversal.
`protein_colinearity.py` retains the inference owner and original evidence order;
its old eager DFS/dedup/sort path is removed from production and frozen only in
`tests/prototypes/exhaustive_ortholog_paths.py` for small oracles.

Default producers return `OrthogroupGraphResult`; `OrthogroupResult` retains its
original tuple fields. `materialize_ortholog_paths(result)` and the explicit
`path_representation="exhaustive"` producer option supply legacy tuples. Explicit
corpus collections preserve supplied paths verbatim and never infer edge closure.

Construction includes node/transition sorting and arbitrary-precision integer
arithmetic; it is not a claim that inference is linear. With V nodes/E chosen
transitions, graph storage is polynomial in V/E and count bit lengths. Explicit
all-path output still costs at least its total output size, including shared
member sorting. No paging, cap, approximation, new analysis mode or cache owner.

## Producer identity and ordering review

A functional check of the frozen S04 public selector found that caller-built
protein maps with keys different from `CdsProtein.protein_id` were accepted.
The initial strict identity rejection was removed before completion. Node IDs
remain the exact map keys; K uses the original protein fields. No identity
normalization is added. Extracted CDS maps have injective K and use the short
DAG prefix/suffix calculation. Equal-K caller inputs use weighted prefix sets
and a constrained suffix DP to compare the full K sequence before the full
edge-ID tuple. Minimum paths through each edge give its first rank without
enumeration. This is polynomial but more expensive than the injective case:
up to O(E * L * (V + E)) DP work, plus sequence comparisons/sorting and integer
bit costs, for maximum path length L. Explicit iteration retains output costs.
120 seeded tied-key DAGs and a public-selector alias example match the frozen
S04 exhaustive oracle, including edge first IDs and stable shared ordering.

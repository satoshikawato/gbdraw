## Changes and equivalence

1. Evaluate aliases in the existing constructor's final argument, then construct
   the unit once. Remove the empty-alias instance and `__dict__` reconstruction.
2. Form `cds_members` directly from `members`. Each group is a subsequence of the
   initial `sorted_proteins`, with the same stable four-part position key.
3. Reduce aliases into the returned unique dict and ambiguous set. A distinct
   second target deletes the unique entry and marks ambiguity permanently;
   repeated aliases for the same unit do not conflict. Surviving keys retain
   their first insertion positions.

The follow-up request, **「Benchmarkは後でいいからまだ削れるところはないの？」**,
explicitly defers measurement. The same owner now also:

- uses `setdefault(alias, unit.unit_id)` instead of a lookup plus a separate
  insertion branch; the ambiguous-alias guard still runs first;
- reuses the known `None` locus ID when converting an auto fallback protein to
  a CDS unit, removing F repeated locus resolutions for F fallback proteins;
- skips the representative's protein/source/SVG alias additions in the member
  loop, since these exact values were already added before that loop. This
  removes three helper calls per representative visit without changing aliases.

Structural tests require one locus resolution per protein and, for unique member
objects, `7P + 3U` alias-add calls instead of `7P + 6U`. No additional container
or mode-specific execution path is introduced. The three further reductions
are recorded in [follow-up](data/s07-6-followup.json).

Initial protein/group sorts, all four independent `_unit_sort_key` minima,
locus priority, representative rank, coordinates, strand, every unit/index
field, ID allocation, protein mapping overwrite order, warning/error behavior,
and input immutability remain unchanged. Fit/numeric/member/RBH/rank logic and
S06/S07 algorithms are untouched. No saved format, raw identity, request,
derived identity or migration changes are required.

`P` is protein count, `U` unit count and `A` unit-alias visits. Construction falls
2U→U; U member sorts involving P references are removed. Per-alias temporary
set allocations fall A→0; the returned ambiguity sets still number R records.
The protein/group sorts, representative selection, coordinates and alias
normalization remain. The whole builder is not claimed to be O(P).

`length_product / query / subject / bitscore` after the existing empty check.
The input frame remains intact. The same pandas stable sorts, bins of
`max(4, ceil(N/8))`, fraction ceil/head, scalar conversion and `math.log10`
produce points in exactly the previous order. Model sums, coefficient order,
score expression, fallback and HSP/coverage selection are unchanged.

The normal fit input has 24 columns. Both global and bin sorts now carry four;
the structural 65-row fixture observes nine sorts, all four columns wide.
The asymptotic sorting work remains `O(N log N + Σ b log b)`. The projection
itself is an additional four-column frame and the original input stays live.

measurements below do not establish an isolated fit-memory reduction.

`normalize_directional_hit_table → fit_expected_bitscore_model →

[S07_LOCAL_REDUCTIONS.md](S07_LOCAL_REDUCTIONS.md).

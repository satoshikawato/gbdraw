## 基準値と限界

native timingはwarmup **1回**、**7 samples**、中央値。profile/counterと
tracemallocは別processで各stage **1回**。`settings.samples` / `warmups`は
timing設定であり、probe/memoryではそれぞれ1 sample / 0 warmupsを使う。
入力準備と結果のhash化はtiming区間の外。各stageは独立に準備した入力を使い、
`post_search`自体にも集計が含まれるため、stage時間を合計してはいけない。

| 対象 | 基準値・観測 |
|---|---|
| Vibrio manifest | 11 records / 24,027 proteins / 保存59方向表。バッチ全validation **1回**、native median **1.429 s**。direction・順序・searchContext・改ざん拒否を確認。 |
| Hepatoplasmataceae Collinear | 5 records / 2,829 proteins、13表、filter後13,720行。post-search median **5.413 s**、tracemalloc peak **17.65 MiB**。 |
| Hepatoplasmataceae Similarity | 同じ5 records、25表、filter後21,935行。post-search median **12.449 s**、MAD **8.84%**で時間判定保留。peak **26.63 MiB**。 |
| Sparse core/unassigned | 200/200 → 400/400 → 800/800: candidate評価 **40,000 / 160,000 / 640,000回**。 |
| Shared helper LRU | 49 / 64 / 81表のwarm hit/miss: **49/0、0/64、0/81**。これはraw searchでなくparse/filterの再実行。 |
| Paths | R=8/12/16: **64 / 1,024 / 16,384 paths**、28/66/120 edges。R=16 selector peak **28.28 MiB**。R≥24は式だけで、列挙していない。 |
| Merge | 300/600/1200 anchors: conflict関数に渡したanchor数 **29,700 / 119,400 / 478,800**。 |
| Browser helper | cold **15.440 s**（Worker初期化込み）、warm median **2.840 s**。各callのJSON換算入力 **22,353,178 bytes**。structured-cloneのwire bytesとは区別する。 |

**時間gateは不合格をそのまま保存した。** 事前固定した基準は中央値10%超の
悪化で`regression`、MAD/medianが5%超なら`inconclusive`。同一本番コードの
2 runでも24 pass / 3 regression / 15 inconclusiveになった。3つの閾値超過は
HSP disjoint/reverse/clamp、small support、Collinear metadata。run内のMADだけでは
run間の系統的な時間差を除けない。最初のrunの冒頭には比較worktreeのcheckoutも
重なったが、それだけで後段の差まで説明できたとはしていない。基準を緩めず、
この環境の秒数を改修による速度差の証拠には使わない。後続の速度判定は同じ
閾値で、競合の少ない環境で両treeを再測定する。operation countと全結果一致は
S03以降の比較に利用できる。

メモリ値はstage内で新たに確保したtracemalloc peakで、準備済み入力を含む
アプリ全体のpeakではない。process RSS最大978,348 KiBはfixture準備・oracle
構築などharnessも含む。保持DataFrameのdeep bytes、RSS、Wasm heapを混同しない。
実browserのWasm peak、raw LOSAT実行時間、全Generateの転送時間分離、mobile、
将来の容量予算や全lifecycle matrixは未測定。S05で必要な実測を追加する。
本番変更がないS01ではfull fast suite全体は実施せず、上記focused gateを選んだ。

## 再現コマンド

採用entryは[`tools/benchmark_protein_comparison.py`](../../../../tools/benchmark_protein_comparison.py)
のみ。Python Playwright adapterはprivate module。**S01 branchのrootから**実行する。
`--source-root`には独立したGit checkoutを指定でき、異なる場所から既にimportされた
`gbdraw`を検出すると失敗する。計測環境・依存version・source status/hash・実際の
argv・入力hash・全sampleは`data/*.json.gz`にある。

```bash
# 別source-rootの基準。既存control worktreeがある場合はその同一HEADを使う。
git worktree add --detach /tmp/gbdraw-s01-control 9a4f7e29ab1b99676bb783321f8a9f40f969d04c
python tools/benchmark_protein_comparison.py run --source-root /tmp/gbdraw-s01-control --measure timing --seed 20260915 --warmups 1 --samples 7 --output /tmp/s01-baseline.json.gz
python tools/benchmark_protein_comparison.py run --source-root "$PWD" --measure timing --seed 20260915 --warmups 1 --samples 7 --output /tmp/s01-current.json.gz
python tools/benchmark_protein_comparison.py compare --baseline /tmp/s01-baseline.json.gz --current /tmp/s01-current.json.gz --output /tmp/s01-time-comparison.json
python tools/benchmark_protein_comparison.py compare --baseline /tmp/s01-baseline.json.gz --current /tmp/s01-current.json.gz --semantics-only --output /tmp/s01-semantic-comparison.json

# 他の時間計測と重ねず、別processで実行する。
python tools/benchmark_protein_comparison.py run --source-root "$PWD" --measure probe --artifacts /tmp/s01-oracles --output /tmp/s01-probe.json.gz
python tools/benchmark_protein_comparison.py run --source-root "$PWD" --measure memory --output /tmp/s01-memory.json.gz
python tools/benchmark_protein_comparison.py compare --baseline /tmp/s01-current.json.gz --current /tmp/s01-memory.json.gz --semantics-only --output /tmp/s01-memory-comparison.json

python tools/prepare_browser_wheel.py --no-build-isolation
python tools/benchmark_protein_comparison.py browser --source-root "$PWD" --output /tmp/s01-browser.json.gz
PYTHONPATH=. python tests/run_losat_cache_browser_acceptance.py --python
```

時間compareのexit codeはpass=0、regression/semantic mismatch=1、inconclusiveのみ=2。
`--semantics-only`は時間の成功を意味しない。狭い再測定には両側で同じ`--cases`を
指定する。タイミング・profile・memoryを同時に実行しない。

実際の成功した実行ログとcommand一覧は[data/verification.json](data/verification.json)。
sourceとwheelの照合は[data/source-proof.json](data/source-proof.json)。
全結果hashは[data/source-comparison.json](data/source-comparison.json)、
[profile照合](data/probe-comparison.json)、[memory照合](data/memory-comparison.json)。
大型出力は同じ`--artifacts`で再生成でき、保存raw/GenBankはtracked Gallery内にある。
小規模・合成入力の28 oracleを`data/oracles/`に保存した。gzipを展開したbytesの
SHA-256が各stageの`semanticSha256`となる。未追跡の過去reportや消失した一時scriptに
再現を依存させていない。

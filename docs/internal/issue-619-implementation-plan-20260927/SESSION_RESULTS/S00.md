### 失敗した境界と比較候補

settings-only Saveの失敗は`gbdraw/web/js/services/session-authority.js::validateSettingsOnlyDocument`の
「Settings-only Session cannot contain committed render artifacts.」。
`gbdraw/web/js/services/config.js::exportSession`はsource-freeでも`runMetadata.annotationWarnings`を常に追加し、
validatorは`Object.keys(data.runMetadata || {}).length`を禁止する。
無編集fresh appも同じ実エラーで失敗し、typed numeric text固有の拒否ではない。
このwriter/validator不整合は既存runtimeの失敗として残した。
error取得のためdownload timeoutをoperation settlement＋実errorの観測へ変えたが、
Save成功条件はdownload必須のまま。metadata削除、checker緩和、fallbackは行っていない。
settings-onlyの表現受理をend-to-endで完了したとは扱わず、後続の開始前に
既存ownerの不整合解決と実Save/Load/native evidenceが必要。
本S00のowner scopeではruntimeを変更できない。

- numericな`NaN`/`Infinity`を直接draftに入れると、既存HistoryのJSON境界が
  bareをnull、typed objectのvalueをnullへ変え、Redoはraw値を復元できない。
  invalid textの`"Infinity"`はこの問題を持たず、保持して拒否される。
  [nonfinite-browser-observations.json](nonfinite-browser-observations.json)では
  History後に元のnonfinite値を戻し、Saveが明示的に拒否することを独立確認した。
  初回matrixのnonfinite `save.accepted:true`は**History後のnullに対するSave**であり、
  nonfinite受理の証拠ではない。writer admissionには再確認JSONを使う。
- typed `{value:true,unit:"px"}`は既存JS validation/payloadで1pxへcoerceされ、
  Web Save/Loadも受理する。一方bare Booleanはvalidationで拒否される。
  bare Booleanはpayload内部でtext化されると`"true"`となるためpayloadも拒否する。
  これらを支持されたnumeric domainのauthorityとみなさない。
- native readerはconfigのinvalid text/nonfiniteも保持する。native typed decoderは
  text value/% unit/nonfiniteを拒否するがtyped 0/負数をdecodeできる。
  [native-request-observations.json](native-request-observations.json)の判定はdecodeだけで、
  geometry planner/renderの正数受理を証明しない。Web payloadの正数条件は維持する。

受理された比較候補は**既存typed objectのvalueにnumeric textを保持**する表現。
有効textは既存boundaryでnumberへ投影、不正textは保持してreject、Autoはnull。
全てをbare suffix文字列で表す候補も既存grammarを持つが、selected unit付きの
不正numeric draftを表すcodecは未検証。別draft shape、persisted unit preference、
raw text requestを追加する候補には今回の受理証拠はない。
非finite numberへ変換する候補、typed empty objectをAutoとして扱う候補は未受理。
この比較は実装前提のevidenceであり、Product選択やschema変更を承認しない。

## 変更owner/pathと削除

Canonical Circular scalarの解釈は既存
`app/track-slot-validation.js::parseOptionalCircularScalar`へ収束した。
validationと`buildCircularTrackSlotPayload()`が同じownerを呼び、返り値は
finite positive numberとpx/factorのpair、またはnull。percentはnumber/100のfactor。
`circular-track-slots.js::circularScalarPayload`を削除した。

`app/circular-track-slots/measure-editor.js`は既存editor owner配下のDOM-free分解。
slot.width/radius以外にdraft、accepted-value mirror、unit array、watcher、registryを持たない。
`services/session-request.js::projectCanonicalCircularMeasure`を削除し、width/radiusの
投影をcodecの共有read helperへ委譲した。純pixel gapsとlegacy pixel spacingは
既存`parseOptionalPixel(..., {allowZero:true})`へ接続する小さなadapterだけを残す。
zeroを受理し、factor/%をpixelへ換算しない。歴史factor spacingのnative replayは
変更せず、現在形式へのlossless Save制約は既存`docs/SESSION_COMPATIBILITY.md`に従う。

変更scopeのcanonical scalar解釈はvalidation/payloadの2独立解釈から1ownerになり、
OEは減少。request→draftのscalar表示ownerはserviceからcodecへ移り、canonical解釈へ委譲する。
Generate→既存session-request→既存typed request/Worker/Result admissionは一つのまま、
PE増加なし。既存scalar grammarと歴史readerを共有boundaryへ接続し、persisted compatibility
path/schemaの追加なし、CB増加なし。例外条件はなく、完全な例外用OE/PE/CB setsは不要。
既存`track-slot-display.js`の丸めるpreview表示はS01のcanonical codecに使わず、
旧inputのsuffix表示と直接bindingの撤去はS02へ残す。
RollbackはS01の4production pathsを一括revertする。前提Save修復とdev mergeを巻き戻さない。

## S02へ渡すinterface

Import先: `app/circular-track-slots/measure-editor.js`。
以下はpure functionsで、slotへの代入・History・Generateを実行しない。

| Export / 引数 | 戻り値・扱い |
| --- | --- |
| `readCircularMeasure(scalar)` | `{valueText, selectedUnit, isAuto, error}`。errorはmessageまたはnull。Autoのunitはnull。有効typed numeric textはその綴りを返す。px suffixは数値部分、percentはcanonical factorの丸めないtext。raw scalarは書き換えない |
| `writeCircularMeasureValue(valueText, selectedUnit)` | selectedUnitは明示`px`/`factor`、valueTextはstring。trim後空欄はnull、非空は既存`{value:text,unit}`。plain textはselectorのunit。有効な完全`20px`/`65%`は同関数の共有adapterが数値＋unitへ取り込む。不正/未完成suffixはtextとselector unitを保持 |
| `changeCircularMeasureUnit(scalar, nextUnit)` | manual scalarの数値lexeme/typed valueを保持してunitだけ変更。同unitは元scalarそのものを返す。invalid textも保持。Autoはnull。R/Result依存の換算なし |
| `projectCircularMeasureDraft(scalar)` | request由来の有効typed pairを同じread viewから既存text draftへ投影（pxのみsuffix）。invalid objectは元のobjectのまま返し、後続admissionが拒否。raw inputをmutateしない |

Canonical parseが必要な既存callerの入口は
`app/track-slot-validation.js::parseOptionalCircularScalar(value, fieldName = 'Circular measure')`。
invalidはErrorで拒否する。codecはerrorをviewへ返してもinvalidをnull/0へ変えない。

S02のowner actionは戻り値を元のslot fieldへ1回だけ適用する。
Auto selector変更はcomponentのtransient preferenceだけを更新する。
**Auto時にunit changeのnullをslotへ代入して、保存済みblankを書き換えてはならない。**
非空のunitは必ずslotから読む。panel remount/Load/Resetのpreference reset、
IME/composition中のadapter呼出時点、focus/change transactionはS02が実装・検証する。
`1.`/`1e-3`はtextのまま、canonical requestはnumber。
読み取りでtyped empty、0、負数、nonfinite、unsupported unitをAuto化しない。
S00のtyped Boolean coercionは支持されたnumeric domainではなく、統一ownerはBooleanを拒否する。
この関連境界はNodeと実browserのSave/Load拒否で確認し、Boolean→1の修復は行わない。
内部nonfinite numberの既存History lossは修復していない。

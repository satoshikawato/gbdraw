## Owners, interface, and removed paths

`app/circular-track-slots/measure-input.js::CircularMeasureInput`をWidth/Radiusで共有する。
propsは`modelValue`, `slotId`, `field`, `controlId`, `autoText`。
emitは`update:modelValue`だけ。非空のtext/unit/errorはS01の`readCircularMeasure`から読む。
numeric setterは`writeCircularMeasureValue`、manual unit setterは
`changeCircularMeasureUnit`へ委譲する。propsをmutateしない。

親の`updateCircularTrackSlotMeasure(slot, field, scalar)`が既存slotのwidth/radiusへ1回代入する。
同じscalar referenceと無効なfield/detached slotはno-op。slot identityと既存WeakMap keyを維持する。
`app.js`がcomponentを登録し、`app-setup.js`はこのowner actionを公開するだけ。
新parser、accepted-value mirror、scalar array、同期watcher、registryはない。

componentの唯一のlocal refはAuto用の次回入力unit。初期・再マウントはfactor（×R）。
Auto selectorはこのrefだけを変え、nullや保存済みblankをslotへ代入しない。
manual unitは常にslotから読み、History restoreでlocal preferenceを逆流させない。
Clearは既存codecからnullを出力する。AutoへのHistory復元でpreference復元を保証しない。
Load/Resetは既存のslot置換とrow keyからcomponentを再マウントし、追加reset signalは不要。

`index.html`の`v-model.trim="entry.slot.width/radius"`直接object bindingと、
Width/Radiusのfloating suffixを同時に削除した。旧suffix ownerのwidth/radius分岐と
そのdisplay-parser importも削除。純pixel gapsとLinearの表示は維持した。
新templateはnative `type="text" inputmode="decimal"`と`v-model.trim`を使う。
slot ID＋fieldをnumeric/unitのaccessible nameへ含め、共通help、field error、Auto情報を
`aria-describedby`で関連付ける。Auto geometryはinput外の単位付きauto情報。

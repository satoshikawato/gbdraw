変更しなかった箇所:
- `buildCanonicalRequestState` の `Boolean(layout.enabled)`（Gallery migration）。Linear の projection は常に boolean の `enabled` を与え、Circular request はこの値を読まないため、観測できる差がない。
- Circular request の `keep_definition_left_aligned=false`。PD-OI-024 が「対応済み旧省略意味」（historical OFF）の保持を求めるため、判断の範囲外として残した。Gallery の Circular file も保存値 false を保持する。

## 3. 保存形式と互換性

- 文書: docs/REFERENCE/session-and-request-compatibility.md（現行の規則）と docs/SESSION_COMPATIBILITY.md（Session 44 の履歴）。

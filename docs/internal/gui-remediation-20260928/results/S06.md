## 4. help-tip

- Lock Definition Column（linear-multi-record spec）: checkbox の accessible description に説明全文。Tab で help button に focus すると表示、Escape で閉じる。hover で表示、離すと閉じる。click で固定し、mouse を離しても表示、checkbox は変わらない。blur で閉じる。390×844 では tap で表示。
- 変異: keyboard focus で開く処理を外すと上の test が失敗した（復元後 SHA-256 一致）。
- popup の Align help-tip は両ボタンの `aria-describedby` の参照先で、layout probe で全 viewport に存在し、常時段落が無いことを確認した。
- 当初は全 177 個の help-tip を button にしたが、全 browser 実行で退行が出た。label 内の button が、その label の control の accessible name に「Help」を加えた（例: Linear の Show Depth が「Show Depth Help」になり visual-state-regressions が失敗）。また summary 内の button が keyboard 順を変えた（history-inputs が失敗）。
- そのため、focus・tap で開く button は常時説明を置き換える help-tip（`id` 付き、今回の 2 件）に限った。他の 175 件は従来の hover icon（`aria-hidden`）のままで、変更前と同じ。移した説明は hover 専用にならない。

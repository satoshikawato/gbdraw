## Changes and measured call requirement

`app/circular-track-slots.js::updateCircularTrackSlotMeasure()` is the supported app action and the only new rejection point. It checks only a bare numeric scalar or the numeric `value` leaf of a typed scalar. For a nonfinite number it invokes the existing `parseOptionalCircularScalar()` error semantics before assigning the slot. Finite numbers, Auto, and all text drafts, including `"Infinity"`, `"1e"`, and `"20em"`, continue through the existing action. The generic JSON clone, scalar parser, Session writer, and request projector were not changed.

`app/rule-matching.js` now exposes its existing match-readiness predicate as `isPrepared()`. The `app/app-setup.js` History callback still reapplies palette and specific rules for config/features restores. It calls `prepare()` for rule-changing or feature-domain restores, and for any other config restore whose current matches are not prepared. The prior invocation on every warm, unrelated config restore was removed. `prepare()` and `isPrepared()` share the same readiness predicate, so rule-changing restores may call `prepare()` without starting a redundant Python helper. The Python helper, SVG application, and History owners remain the same.

# S04 mutation and checkpoint evidence

Acceptance: **S-02**. This inventory describes production entry points; it is not a second policy/decision registry.
The [structured inventory](S04-mutation-inventory.json) lists each guarded action, its owning state, DOM/programmatic entry and completion checkpoint, plus native template bindings. Private admission/normalization helpers run only inside the existing Session/Result owner. They are not alternate user mutation paths.

Every semantic entry uses `state.sessionOperationAvailability()` or its injected identical function. Native controls derive `semanticMutationAvailable` from that function. Save/Load additionally derive reasons from existing Generate/reflow flags and actual pending History/edit/import/definition resources. No second lock ref or generic queue was added.

Read-only scroll, viewport pan/zoom, search, popup/drawer tabs, close and text/sequence downloads remain available. Result selection flushes the persisted SVG and replaces its editor binding, so its existing owner uses semantic admission. Persisted diagram/title/legend/length-bar drag differs from viewport pan and uses semantic admission at start and position updates.

| Checkpoint | Owner/state and evidence |
| --- | --- |
| Save admission | `config.exportSession`: exact duplicate promise joins before busy. Cross Load returns explicit reason. Title cancellation publishes no pending. Save native button is History-ignored; an idle focused input is not asynchronous edit work. |
| Save publication | Existing flag published, small mutable config/UI copied, then app `nextTick`/paint. Immutable adopted request/resources/catalog/cache/Result payloads retain existing ownership. |
| Save preparation/handoff | Uncataloged Linear files prepare record descriptors privately; no live automatic expansion. Existing all-record canonical request retains exact source bytes. Compression, size/repeat cancellation, download and error use existing serialization. Lifetime checked after awaited work and before handoff. |
| Async edit preparation | Actual History transaction (deferred adapter commit), helper, definition timer/promise and auxiliary-file promise prevent Save/Load from entering mid-edit. Successful/error discovery completion verifies source identity and Session availability; deferred discovery retries after settlement. Rule/helper replies cannot publish stale caches. |
| Generate/reflow | Existing processing flag owns source preflight through final UI reconciliation; reflow flag owns all queued iterations. Save/Load returns Generating/Updating reason and retry continuation. No new Worker. |
| Load private preparation | JSON/gzip validation, migrations, resource/file reconstruction, sequence/catalog recovery plan and SVG admission finish before reset/adoption. Existing parser/normalizers retained. |
| Load adoption | Existing transaction assigns source/config/request/resources/features/cache/Results and readiness expectation before first adoption yield. Normal edit watchers skip adoption and pending. Inactive mode profiles are imported by their existing owner; deferred mode watcher does not invalidate them. |
| Failed adoption | Restore main config/source/request/resources/Result/cache/evidence before `nextTick`, then transient selection/discovery/layout reconciliation. Immutable references survive; old History is not cleared before candidate/preview success. |
| Load History | Baseline is inside the rollback scope. A current-lifetime check follows baseline capture before stack clearing. Controlled baseline error and teardown both restore the previous document and History. |
| Settlement | Same operation identity clears its flags; canceled stale Save cannot download or clear a newer Load. Unmount calls existing operation disposal and definition/Worker teardown. |

The new browser cases exercise independent app/History/placement owners with invalid arguments so busy must win admission, real pointer pan/wheel and keyboard search, duplicate/cross operations, source-first rollback reference equality, real Generate and automatic reflow, teardown, baseline failure, and uncataloged multi-record draft Save. Node cases cover late History capture/command, real asynchronous transaction ownership, idle focus, canceled baseline, delayed annotation/source/rule replies. Existing lifecycle, S03, settings-only, auxiliary History and palette cases remain acceptance evidence; failures and corrected reruns are recorded in S04_RESULT.

Architecture: availability is owned by state; service config owns the operation lifetime. The app Save singleflight was removed, leaving one public service path and app UI adapters. File reconstruction accepts a private target through the existing owner; the superseded live legacy recovery helper was removed. Generate/reflow retains one owner for each existing flag. New derived UI refs and actual promise/timer handles are not additional document/lock authority. No new compatibility branch, parser, schema, Worker, privileged operator/importer, active registry, checker or public default. Complete exception sets are not invoked; local Gate and Review remain independent.

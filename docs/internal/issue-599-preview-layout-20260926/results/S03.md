## Owner と実装

`index.html` に検索 auto row、中央 `preview-workspace`、下部操作 auto row の単一 grid を置いた。既存 canvas、SVG、Editor を同じ workspace に入れ、drawer の containing block を workspace にした。検索と toolbar は workspace の兄弟であり、drawer 内部の overflow も drawer 枠内に収める。compact 幅では同じ Editor と alignment review を canvas 下へ dock し、alignment palette の従来の bounded height と内部 scroll を保持する。短い画面では card/page または Result pane が scroll する。検索と toolbar は各1 DOMで、Run info への切替は `v-show` による visibility のまま。

旧 `.preview-feature-search` の absolute 位置、grab cursor、inline transform、固定 `RIGHT_DRAWER_WIDTH_PX`、`dragOffset` / `activeDrag`、位置 computed、start/move/stopDrag、global pointer/blur listener、Vue export、template style/drag binding を同じ変更で撤去した。旧 `.preview-controls` の absolute/translate と drawer-open 退避、mobile/container-query の競合 `!important` solver も削除。feature popup 等の 360px と `right-drawer` 自身の幅は変更していない。新しい座標 ref、ResizeObserver、collision solver、別 Editor、設定 toggle はない。

Architecture: search 意味は既存 `feature-search/preview-actions.js`、chrome geometry は `index.html`、visibility/tab は既存 `right-drawer.js` の単一 owner。追加 owner/path/compatibility branch なし。superseded search position path は削除したため通常の非増加 ratchet として扱う。

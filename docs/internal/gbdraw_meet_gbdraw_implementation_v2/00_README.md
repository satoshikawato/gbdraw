## 動画の編集パートと視聴者体験

同じヒトミトゲノムで、productラベル→geneラベル、CDS単一色→全13 CDSの4機能カテゴリ配色、原点をまたぐD-loop領域注釈ブラケットの追加を順に示します。各4秒のBefore/Afterで、合計12秒です。

- **静止画フリーズ誤認の防止**: P1（geneラベル）およびP2（機能別配色）の静止画がBefore/Afterの遷移で連続する区間では、字幕を次のステップへの目的予告とし、視聴者に動画が停止したと誤認させずスムーズな編集ステップとして知覚させます。
- **視線誘導（Visual Spotlight）**: 2秒のAfterシーンにおいて、変化した領域（代表遺伝子名、凡例、D-loopブラケット）への控えめな視線誘導（アテンション枠）を施し、視聴者が瞬時に変化を理解できるようにします。
- **D-loop領域注釈ブラケット（Region Annotations）の実演**: 公式チュートリアル（`highlight-mitochondrial-features.md`）の花形機能である、原点をまたぐD-loopブラケット注釈を実演し、gbdrawの先進的なトラック・注釈機能を強力にアピールします。
- **研究者へのベネフィット訴求**: 論文投稿や学会発表を意識し、「ベクターSVGの出力（Publication-ready vector SVG）」および「完全ブラウザー完結動作（Runs in your browser）」を字幕とOutroで明確に訴求します。
- **多面的アセット展開**: 完成動画（`meet-gbdraw.mp4`）に加え、GitHub README用の軽量ループアニメーション（`meet-gbdraw.webp`）および学会スライド用単体チャプタークリップ（`chapters/*.mp4`）を自動出力します。
- **SSIMによる自動画像回帰判定**: 人間の目視だけに頼らず、FFmpegのSSIMフィルターを用いた機械的ビジュアルリグレッションテスト（`check --visual`）を確立します。

## 利用方法

総合計画書を実装担当者が読める場所に置き、S1からS5の順に、担当セッションのINSTRUCTION PROMPT全文を渡してください。各ファイルはそのまま指示文として使用できます。1セッションで5段階をまとめて実装させる指示ではありません。

各担当者は自分のセッションを実装・検証し、リポジトリ内の`docs/videos/meet-gbdraw/handoffs/Sn.md`へ実値の引き継ぎを残します。次の担当者は、その記録だけを信用せず、実コードと成果物を確認して続行します。

## 重要な境界

参照コミットは資料の版を特定するためのものです。実装開始時には現在の`AGENTS.md`等を読み、現在のブランチ規則に従ってください。エージェントの新規ブランチは最新`origin/dev`起点です。

制作工程は「正しい素材を取得する工程」と「素材を動画へ編集する工程」を分けます。字幕だけの変更でブラウザーやLOSATを起動しないこと、既存の承認済み画像を変えないこと、失敗を古い成功素材で隠さないことを受け入れ条件にしています。

動画作成と公開承認は別です。この指示一式は無断のcommit、push、PR作成、merge、SNS投稿、公開サイト変更を要求しません。リモート操作は別の明示指示に従います。

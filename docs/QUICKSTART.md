# Quickstart

Choose the interface you want to use. Each Tutorial starts from a bundled, version-pinned genome and produces a checked SVG without downloading live data.

## Web app

Use [Create and export your first circular genome diagram](./TUTORIALS/GUI/first-circular-genome-diagram.md) if you want to work in the browser without writing commands. The first preview appears in Step 2.

## Command line

Use [Create a reproducible circular diagram from the command line](./TUTORIALS/CLI/first-circular-genome-diagram.md) for a copyable, clean-directory workflow.

## Python

Use [Draw and save your first genome diagram from Python](./TUTORIALS/PYTHON/first-genome-diagram.md) for the minimal public API workflow.

After your first diagram, choose a focused [How-to guide](./HOW_TO/README.md). Exact controls, options, schemas, APIs, and output behavior live in [Reference](./REFERENCE/README.md).

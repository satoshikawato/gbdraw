# Command-line reference

The executable has three entry points:

| Command | Purpose |
|---|---|
| `gbdraw circular` | Draw one Circular result, a multi-record canvas, or a batch of Circular results. |
| `gbdraw linear` | Draw one ordered Linear result with optional comparisons. |
| `gbdraw gui` | Serve the packaged web application locally. |

Run `gbdraw --help`, `gbdraw circular --help`, or `gbdraw linear --help` for the option inventory generated by the installed version. The [generated CLI option inventory](../CLI_Reference.md) lists every flag. This page is the canonical owner of current command semantics and surface boundaries; Tutorials and How-to guides own runnable workflows.

## Shared input rules

GenBank input uses `--gbk`. GFF3 uses `--gff` with a matching `--fasta`. A records table replaces those direct path lists and keeps record-specific selectors, regions, orientation, labels, and placement together. Relative paths inside a TSV resolve from that table's directory.

Repeated input lists are positional. A repeatable label, subtitle, reverse-complement flag, region, depth source, or comparison edge must map to the intended displayed record after selection and ordering.

## Comparison boundary

`--protein_blastp_mode` can run Pairwise, Similarity-group (`orthogroup` compatibility token), or Collinear protein comparisons through LOSATP or BLASTP. LOSATN and TLOSATX are not CLI search modes. Read their prepared evidence with `--blast`, `--comparisons_table`, or `--conservation_blast`.

`--protein_blastp_output PATH.tsv` writes the raw protein-search entries from
the same Linear run into one deterministic, commented outfmt 6 file. It
hydrates session-internal runtime handles to stable, percent-encoded protein
IDs and refuses an existing file unless `--overwrite` is present.

## Output rules

SVG is always written as the base result. Additional formats are selected with `-f` or `--format`. A prefix is one filename component; the output directory is a separate option or request field. Existing output is rejected unless overwrite is explicitly enabled. See [Output formats and export](output-formats-and-export.md).

## Error behavior

Invalid input combinations, unknown schema columns, mismatched record selectors, impossible layouts, incompatible track stacks, and unsafe output paths fail before a successful result is reported. Warnings identify ignored combinations such as an on-axis ruler without an above/below Linear track layout. A warning does not change the documented command into a successful use of that option.

# Web app Tutorials

Start with one complete path and its accession-pinned biological input.

Download every sequence from the authoritative database linked by its
Tutorial, using the exact local filename shown. The [tutorial-input
guide](../../GETTING_TUTORIAL_DATA.md) explains how to keep authoritative
sequences, repository support data, files you create, generated outputs, and
reference results separate. Do not start from a bundled sequence or Gallery
session.

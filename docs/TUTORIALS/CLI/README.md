# Command-line Tutorials

Each Tutorial starts with an empty working directory, labels every file as
Download, Create, Generated, or Reference result, and gives an exact command
you can run. Read [Get the tutorial files](../../GETTING_TUTORIAL_DATA.md) for
browser, `curl`, and PowerShell download methods.

The documented commands run from clean temporary directories. Sequence
records come from accession-pinned NCBI or MIBiG downloads; repository-hosted
files are limited to the supporting tables named by each Tutorial.

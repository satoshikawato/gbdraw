# Tutorials

Each Tutorial builds one complete figure from downloaded inputs. Its page
shows the finished figure first, lists the inputs once, and then gives the
steps for the web app, the command line, and Python, in that order. Follow the
section for the interface you use.

## Start here

If this is your first gbdraw figure, start with
[Draw a labeled circular map of the human mitochondrial genome](first-circular-genome-diagram.md) or
[Draw a labeled linear map of the Lambda phage genome](first-linear-genome-diagram.md). Read [Get the tutorial
inputs](../GETTING_TUTORIAL_DATA.md) before your first download.

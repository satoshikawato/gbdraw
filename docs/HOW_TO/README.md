# Task guides

Task guides are focused How-to procedures. They start from a known state and
solve one specific job that you can adapt to your own data; they do not teach a
complete fixed project from beginning to end.

Each guide names its inputs, actions, expected output, verification, and known
failure modes. Use [Get the tutorial inputs](../GETTING_TUTORIAL_DATA.md) for the
shared download procedure, then choose the interface you are using:

- [Web app](GUI/README.md)
- [Command line](CLI/README.md)
- [Python](PYTHON/README.md)

If you have not made a diagram yet, start with a [Tutorial](../TUTORIALS/README.md).
For complete option, schema, or format details, use
[Technical reference](../REFERENCE/README.md).

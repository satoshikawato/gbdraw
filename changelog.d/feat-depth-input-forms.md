- Added: Depth tracks read a two-column table of position and value, and a bedGraph file (reference, 0-based start, end, value), besides `samtools depth` output, on the command line, in Python and in the Web app. gbdraw tells the form by the number of columns, and skips comment, `track` and `browser` lines before the rows. See [Comparison and numeric tables](./docs/REFERENCE/input-formats-and-tsv-schemas.md#comparison-and-numeric-tables).
- Changed: a depth file of four or more columns is read as bedGraph, whose rows must come in increasing order without overlapping. A `samtools depth` file of several samples still draws its first sample when it has the header line `samtools depth -H` writes; without it, the file is refused with a message that says to keep one sample's column or to add `-H`.
- Fixed: a depth value of `nan`, `inf` or nothing, in a file or a Python depth table, stopped the Depth track from that position to the end of the record without a message; it is now refused with the reason.

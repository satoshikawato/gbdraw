- Added: Depth tracks read a two-column table of position and value, and a bedGraph file (reference, 0-based start, end, value), besides `samtools depth` output, on the command line, in Python and in the Web app. gbdraw tells the form by the number of columns, and skips comment, `track` and `browser` lines before the rows. See [Comparison and numeric tables](./docs/REFERENCE/input-formats-and-tsv-schemas.md#comparison-and-numeric-tables).
- Changed: a depth file of four or more columns is read as bedGraph. A `samtools depth` file of several samples, which earlier drew its first sample, is refused with a message that says to keep one sample's column.
- Fixed: a depth value of `nan`, `inf` or nothing stopped the Depth track from that position to the end of the record without a message; such a file is now refused with the reason.

- Added: each numeric series (a depth track) names the format of its file: `auto` (as before), position and value, `samtools depth`, bedGraph, or BED. A BED file draws its scores, or counts its rows when they have none, and its rows may overlap and come in any order, so a file of variant or insertion sites read with the window sum draws how many fall in each window. A `samtools depth` file of several samples, read as `samtools`, draws its first sample with or without its header line. Command line `--depth_track_format`, Python `format`. See [Comparison and numeric tables](./docs/REFERENCE/input-formats-and-tsv-schemas.md#comparison-and-numeric-tables).
- Added: a numeric series may hold negative values, such as a log2 ratio, and draws them on both sides of its baseline; only a log-scaled track refuses them. The automatic range runs from the smallest value (0 when none is below 0) to the largest, and the global Depth Min and Max accept negative values.
- Added: per-series settings on the command line, in Python and in the Web app: the window value (mean, largest value or sum, `--depth_track_agg`), the baseline the series is drawn from (automatic, the mean or a value, `--depth_track_baseline`), its own value range (`--depth_track_min`, `--depth_track_max`), the style (filled area or line, `--depth_track_style`), a colour for the part below the baseline (`--depth_track_negative_color`), and the unit after each axis number (`--depth_track_unit`; `x` by default, empty for none). Every default draws as before. See [Numeric series settings](./docs/REFERENCE/web-app.md#numeric-series-settings).
- Added: the Web app sets these per series in each series card of Circular "Numeric series tracks" and Linear "Depth track settings", saves them in the Session, and gives them as command-line options in Run Info. The file pickers also offer `.bedgraph`, `.bdg`, `.bg` and `.bed` files.
- Fixed: a depth track of the Python API (`gbdraw.DepthTrackOptions`) without a label or a colour drew a Legend row "None" and no fill; it draws "Depth" in the default colour.
- Fixed: the Linear "Shared Y-axis" checkbox label of the Web app broke as "Shared Y-" / "axis" in the desktop sidebar, and in some languages a long label of the Depth checkboxes ran under the checkbox beside it; each label now keeps its words whole and inside its column.
